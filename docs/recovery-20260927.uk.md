# Відновлення MT5 — 2026-09-27

Neon production доступ відновлено. До ремонту останній успішний збір був
2026-09-26 13:18:49 UTC; запущені термінали не означали, що імпорт працює.

## Причини

- Автооновлення встановило MT5 6230 у demo-01/02/03 і 6204 у demo-05.
  Worker і API дозволяли тільки 6182/6190/6193. Результат: спочатку
  INVESTOR_UNVERIFIED, а при односторонньому оновленні worker — HTTP 400 complete.
- Production Watch-Worker.ps1 використовував Start-Process -Wait, який очікує
  також дочірні термінали. Після завершення Python supervisor не відновлював його.
- Три QUEUED рахунки пропускалися через існуючу політику неактивності понад 7 днів.
  Активність користувачів і політика не змінювалися.

## Зміни

- Через Computer Use підтверджено явні Read Only / Hedge заголовки:
  6230 — Exness, BrightFunded, FundingPips; 6204 — Headway.
- Додано тільки ці дві збірки до allowlist. Ідентичність, режим доступу,
  заборона Python trading і всі інші перевірки залишилися обов'язковими.
- API commit b6f2a77bc8704607dda846d02d35780357fe444e запускає Fly deployment.
- Watch-Worker.ps1 очікує тільки launcher через Process.WaitForExit(); перезапущено
  тільки supervisor, без завершення дерева процесів або робочих терміналів.
- Створено broker Headway та REVIEWED Headway-Real. Основний connection
  cmu09bn10000h04le39jkijpk виправлено з Headway real на Headway-Real,
  credentialVersion 2 -> 3; зашифрований пароль не змінено й не виведено.
  Дублікат Hea залишено вимкненим. Вхід Headway-Real 16933402 підтверджений
  живим заголовком Read Only; це ще не саме підтвердження імпорту.

## Перевірки

144 Python тести пройшли. API nest build та ESLint зміненого schema пройшли.
PowerShell parser не знайшов помилок у зміненому supervisor.
Стан deployment і фактичний збір потрібно перевіряти окремо після rollout.

Майбутній невідомий build усе ще навмисно не приймається: автоматичне розширення
списку без перевірки UI було б ослабленням контролю доступу.
