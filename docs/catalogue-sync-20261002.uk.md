# Каталог MT5 та відновлення watchdog — 2026-10-02

## Поведінка

- Поле Server використовує точні назви зі свіжого позитивного звіту `login_dialog` хоча б одного робочого слота. Відсутні, прострочені, помилкові та карантинні слоти не підтверджують доступність.
- API автоматично реєструє невідомі точні назви з автентифікованого позитивного звіту. Невідомого брокера не вгадує: використовується `Custom MT5 servers`. Архівні записи не відновлюються автоматично.
- Worker поширює каталог із більшим набором назв на вільні слоти з його підмножиною. Не чекає наступної заявки користувача. Опитування та синхронізація мають різні таймери.
- За цикл змінюється максимум один слот. API атомарно блокує нові задачі під час підготовки. Підтверджуються процес, покоління, збірка, SHA-256 і свіжість інвентаризації; після заміни потрібен новий позитивний звіт.
- Копіюється лише `config/servers.dat`; попередній файл зберігається для відновлення. `accounts.dat`, паролі й токени не копіюються.
- Якщо штатне закриття зависло, повторно перевіряється блокування API, покоління й точна ідентичність процесу. Завершується лише цей заблокований процес, потім встановлюється каталог та запускається термінал.
- Розбіжні каталоги, де жоден не містить усіх назв іншого, не перезаписуються: їх треба попередньо звести в перевірений спільний каталог. Файли різних збірок також не копіюються.
